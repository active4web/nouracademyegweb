# خطة صفحة دليل الكورسات (`/courses`)

## 1. هيكل السكاشن وآلية التفاعل (Page Sections & Interactions)

* **01. هيدر الدليل ونموذج البحث الموجه (Courses Hero & Search Form)**
  * العنوان الرئيسي والوصف التعريفي بالمسارات التعليمية الشاملة.
  * نموذج بحث (`<form>`) يتضمن حقل إدخال وزر إرسال تفاعلي.
  * **سلوك البحث (Search on Submit):** عند الضغط على مفتاح `Enter` أو زر "بحث"، يتم تطبيق استعلام البحث والتمرير السلس التلقائي (Smooth Scroll) نحو سكشن شبكة الكورسات (`#courses-grid`).
  * عداد إجمالي الكورسات المتاحة والمحدث ديناميكياً.

* **02. سيكشن العرض والفلترة المتقدمة (Courses Listing Section - `id="courses-grid"`)**
  * **شريط الفلاتر والتصنيفات:**
    * تصنيفات المسارات: (الكل، القرآن الكريم والحفظ، التجويد والقراءات، اللغة العربية، الأطفال، الدراسات الإسلامية).
    * تصفية سريعة حسب الفئة المستهدفة والمستوى (مبتدئ / متوسط / متقدم).
  * **شبكة بطاقات الكورسات (Courses Grid):**
    * بطاقات تفاعلية بتصميم متجاوب يعرض: صورة الغلاف، شارات التصنيف والمستوى، عنوان الكورس، ملخص المنهج، وتفاصيل الحصص.
    * روابط التوجيه المباشرة: زر صفحة تفاصيل الكورس (`/courses/[id]`) وزر الحجز المباشر (`/courses/[id]/apply`).
  * **واجهة حالة البحث والنتائج:**
    * شريط تنبيهي يوضح الكلمة المبحوث عنها وعدد النتائج المطابقة.
    * واجهة خلو النتائج (Empty Search State) عند عدم العثور على نتائج، مزودة بزر "إعادة تعيين البحث" لاسترجاع كافة الكورسات بسلاسة.

* **03. البانر الختامي المعتمد (Final CTA Section)**
  * إعادة استخدام مكون `FinalCtaSection` المشترك لحجز الحصة التجريبية وتحديد المستوى.
