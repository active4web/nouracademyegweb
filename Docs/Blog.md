# خطة صفحة المدونة والمقالات (Blog Page Structure) - `/blog`

تهدف صفحة المدونة إلى إثراء معرفة الطلاب وأولياء الأمور بمقالات متخصصة في علوم القرآن، التجويد، اللغة العربية، والنصائح التربوية، مع إتاحة بحث وتصفية سلسة بالـ Framer Motion وترقيم صفحات تفاعلي.

---

## 1. هيكل ملف البيانات (Data Model) - `src/data/blog.data.ts`
* **المسار:** `src/data/blog.data.ts`
* **نوع البيانات:** `BlogPost` interface يدعم تعدد اللغات (ar/en).
* **الحقول الأساسية لكل مقال:**
  * `id` / `slug`: المعرف والمسار للمقال.
  * `title`: عنوان المقال (ar/en).
  * `excerpt`: ملخص المقال المعروض في الكارت (ar/en).
  * `content`: محتوى المقال الكامل (HTML / Markdown strings).
  * `category`: تصنيف المقال (علوم القرآن، تجويد، لغة عربية، تربية أسرية).
  * `author`: بيانات الكاتب (الاسم، اللقب، الصورة).
  * `publishedAt`: تاريخ النشر.
  * `image`: صورة المقال الرئيسية.
  * `featured`: حقل بولياني لتحديد المقال الرئيسي المميز.

---

## 2. هيرو المدونة والمقال المميز (Blog Hero & Featured Post Section)
* **المسار:** `src/features/Blog/BlogHeroSection/`
* **نوع المكون:** Server Component.
* **المحتوى:**
  * شارة تعريفية (Badge) تدل على مقالات وأبحاث نور الأكاديمية.
  * عنوان رئيسي ونبذة مختصرة عن المدونة.
  * بطاقة المقال المميز (Featured Post Card): عرض كارت كبير وعريض لأحدث أو أهم مقال، يحتوي على (الصورة، التصنيف، تاريخ النشر، الكاتب، العنوان، والملخص وزر الانتقال للمقال).

---

## 3. شريط البحث والفلترة وشبكة المقالات (Blog Listing & Filter Section)
* **المسار:** `src/features/Blog/BlogListingSection/`
* **نوع المكون:** Client Component (مع Framer Motion).
* **المحتوى:**
  * **شريط الفلترة والبحث:**
    * تصنيفات المقالات (الكل، علوم القرآن، أحكام التجويد، اللغة العربية، نصائح وتوجيهات).
    * حقل بحث سريع بالنص المباشر (Search Input).
  * **كارت المقال الموحد (`BlogCard`):** مكون قابل لإعادة الاستخدام في الهوم وصفحة المدونة:
    * صورة المقال + وسم التصنيف.
    * تاريخ النشر + اسم الكاتب.
    * عنوان المقال + النبذة المختصرة.
    * زر "اقرأ المزيد" مع سهم تفاعلي.
  * **ترقيم الصفحات (Pagination Controls):** أزرار تنقل بين الصفحات السابقة والتالية وأرقام الصفحات.

---

## 4. البانر الختامي المشترك (Blog Final CTA Section)
