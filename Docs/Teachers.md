# خطة صفحة المعلمين (Teachers Page Structure) - `/teachers`

تهدف صفحة المعلمين إلى استعراض نخبة معلمي أكاديمية نور (من حفظة القرآن الكريم، الحاصلين على الأسانيد العالية، ومعلمي اللغة العربية المتخصصين) مع إتاحة فلترة دقيقة وسهولة حجز الحصص أو تصفح الملفات الشخصية.

---

## 1. هيرو المعلمين (Teachers Hero Section)
* **المسار:** `src/features/Teachers/TeachersHeroSection/`
* **نوع المكون:** Server Component (لدعم الـ Metadata والـ SEO).
* **المحتوى المستهدف:**
  * شارة (Badge) تعريفية تدل على نخبة المعلمين والأزهر الشريف.
  * عنوان رئيسي يبرز تميز الكادر التعليمي (معلمون مجازون بشهادات وأسانيد متصلة).
  * نبذة تعريفية توضح أساليب التدريس الفردية المخصصة للأطفال والكبار.
  * مؤشرات ثقة سريعة (عدد المعلمين المعتمدين، نسب رضا الطلاب، التخصصات المتاحة).

---

## 2. أدوات الفلترة وشبكة المعلمين (Teachers Grid & Filter Section)
* **المسار:** `src/features/Teachers/TeachersGridSection/`
* **نوع المكون:** Client Component (لتشغيل الفلترة التفاعلية بسلاسة).
* **المحتوى والعناصر:**
  * **شريط الفلترة (Filter Bar):** تصنيف المعلمين حسب التخصص (تجويد وقرآن، حفظ وتثبيت، لغة عربية، تلاوة للأطفال) أو حسب الجنس (معلم / معلمة).
  * **شبكة الكروت (Teachers Grid):** عرض بطاقات المعلمين بتصميم متجاوب (Responsive).
  * **محتوى البطاقة الفردية (Teacher Card):**
    * صورة المعلم / المعلمة الشخصية.
    * الاسم واللقب العلمي (مثال: شيخ / مقرئ مجاز بالسند).
    * التخصص الرئيسي ونبذة مختصرة.
    * تقييم المعلم (النجوم) وعدد الحصص أو الطلاب المكتملة.
    * زر "عرض الملف الشخصي" (`/teachers/[id]`).
    * زر سريع "حجز حصة" (`/teachers/[id]/apply` أو حجز تجريبي).

---

## 3. معايير اختيار واختبار المعلمين (Why Our Teachers / Standards Section)
* **المسار:** `src/features/Teachers/TeachersStandardsSection/`
* **نوع المكون:** Server Component.
* **المحتوى:**
  * توضيح الشروط الصارمة في اختيار طاقم التدريس بأكاديمية نور.
  * إبراز حصولهم على إجازات متصلة السند بالنبي ﷺ.
  * الدورات التربوية والمهارية في التعامل مع مختلف الفئات العمرية (خصوصاً الأطفال).

## 4. بانر انضمام المعلمين (Teacher Application CTA Section)
* **المسار:** `src/features/Teachers/TeacherJoinBanner/`
* **نوع المكون:** Server / Client Component.
* **المحتوى:**

  * زر مباشر لتقديم طلب انضمام.
